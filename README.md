# 📊 Dashboard de Vendas — BYD

Projeto prático desenvolvido durante o curso **AI Reports com Excel, GPT Agents e Claude Code**, do Santander.

O projeto consiste na criação de um dashboard interativo para análise de dados de vendas da BYD, utilizando **DADOS FICTÍCIOS EXCLUSIVAMENTE PARA FINS EDUCACIONAIS**.

##  Objetivo

Desenvolver uma solução de análise de dados capaz de transformar informações de vendas em indicadores e insights para apoiar a tomada de decisões.

O dashboard permite explorar informações como:

* 🚗 Modelos mais vendidos
* 📍 Vendas por cidade
* 📅 Model Year
* 💳 Forma de pagamento
* 📈 Indicadores gerais de vendas

##  Ferramentas utilizadas

* **Microsoft Excel** — organização e preparação dos dados
* **Claude** — apoio no desenvolvimento do dashboard
* **GPT Agents** — aplicação de inteligência artificial no processo de análise
* **HTML, CSS e JavaScript** — estrutura e interface do dashboard
* **GitHub Pages** — publicação do projeto

##  Inteligência Artificial

Durante o desenvolvimento, foram explorados recursos de IA apresentados no curso, incluindo:

* AI Reports com Excel
* GPT Agents
* Claude Code
* Agente de tratamento de dados

A IA foi utilizada como apoio na estruturação, tratamento e desenvolvimento da solução.

##  Dashboard

O projeto apresenta uma interface interativa para exploração dos dados e visualização dos principais indicadores de vendas.

###  Filtros disponíveis

* Modelo do BYD
* Model Year
* Cidade
* Forma de pagamento

##  Dados

Os dados utilizados neste projeto são **fictícios** e foram criados exclusivamente para fins educacionais e de demonstração.

Eles não representam dados oficiais da BYD.
